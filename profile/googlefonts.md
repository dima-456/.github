# How to install Google Fonts
We are using Google Fonts in this class for ease of install and so we don't have to host our own typography files. To get them set up in your portfolio repo, follow these steps.

Find the fonts you want to use and add them to your cart. When you are done and ready to install, click the shopping basket icon in the top right of the web page.

![fontsgetembed](https://github.com/user-attachments/assets/90d5b9e7-1c18-4c7a-a66b-a21cdcf03edb)

Click "Get embed code." You can also download them, if you'd like, and want to use them on your local machine for other projects.

![switchtoimport](https://github.com/user-attachments/assets/a0724d21-ef94-431b-bec9-13704a5e128e)

Click to get the "@import" code.

![whattocopy](https://github.com/user-attachments/assets/14f4e636-50da-4a53-96a4-0236738e9dc2)

Copy the line of type that begins with `"@import ..."` and place it at the very top of your portfolio's `style.css ` document. Be sure to include the `; ` at the end.

You can now call in your fonts using their names. For example, if I embedded the Funnel Sans font, I could add this line where I want to see it: `font-family: 'Funnel Sans', sans-serif;`.
